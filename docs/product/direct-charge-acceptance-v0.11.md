Evidence: each gate maps to automated regression tests and where necessary actual provider sandbox/configuration tests, authoritative provider documentation and account-specific written approval or approved controlled verification of production-only behavior before general live enablement. Record exact API version, account controller/dashboard/capabilities, environment, commit, test name/command, redacted provider object IDs/events, expected/actual, timestamp, reviewer and pass/fail/blocked. No credentials or PII in public repo. Independent review must be real, not self-attested. No test/approval fabricated; no live financial operation to prove gate without separate authority. If Stripe configuration cannot meet a mandatory control, halt and escalate architectural decision rather than weakening safety, silently switching charge type or imposing new costs.
