# Architecture v0.2 — delegated design, proposed for review

Existing Node scaffold unchanged. Owner delegated stack and requested aggregate infrastructure under S$50/month. Choose Next.js + TypeScript installable PWA, Tailwind/shadcn, Zod, modular monolith, typed repository ports, Vitest/Playwright, Terraform/GHA; GCP Singapore. Pilot Firestore Standard native mode rather than three continuously billed Cloud SQL instances (deliberate departure from v0.1 PostgreSQL proposal); usage billing and local emulator. No ORM needed. Revisit PostgreSQL if transaction/relational needs or compliance require it. Cloud Run min instances 0, Google OIDC server sessions, private Cloud Storage, Cloud Tasks/Scheduler, AI provider-independent adapter with deterministic fallback, structured logs and aggregate snapshots; BigQuery on demand if needed. No always-on workers, paid search or microservices initially.
Modules identity, catalogue, requests, trips, offers/orders, money/reconciliation, handover/evidence, disputes, reviews, growth, analytics. Server-only authoritative writes; Firestore transactions with deterministic guard IDs for reservation, balanced immutable journal, outbox, idempotent external calls outside retried transactions, disputes and referral cap. Verify contention, limits, indexes, reconciliation in emulator + stg; if integrity cannot be proven block live money and revisit storage. Backups and restore drill before real funds. Repository contracts and export format preserve portability. SGD minor units only in payment path, no Stripe FX; future currency/corridor modeled separately. Private uploads scanned, signed links, RBAC, retention, provenance. No secret or raw receipt in agent analytics.
