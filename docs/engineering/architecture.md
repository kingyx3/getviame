Existing Node scaffold unchanged. Owner delegated stack and requested aggregate infrastructure under S$50/month. Choose Next.js + TypeScript installable PWA, Tailwind/shadcn, Zod, modular monolith, typed repository ports, Vitest/Playwright, Terraform/GHA; GCP Singapore. Pilot Firestore Standard native mode rather than three continuously billed Cloud SQL instances (deliberate departure from v0.1 PostgreSQL proposal); usage billing and local emulator. No ORM needed. Revisit PostgreSQL if transaction/relational needs or compliance require it. Cloud Run min instances 0, Google OIDC server sessions, private Cloud Storage, Cloud Tasks/Scheduler, AI provider-independent adapter with deterministic fallback, structured logs and aggregate snapshots; BigQuery on demand if needed. No always-on workers, paid search or microservices initially.
Modules identity, catalogue, requests, trips, offers/orders, money/reconciliation, handover/evidence, disputes, reviews, growth, analytics. Server-only authoritative writes; Firestore transactions with deterministic guard IDs for reservation, balanced immutable journal, order-linked payment allocations and separately restricted promotional grant lots with atomic reserve/redeem, outbox, idempotent external calls outside retried transactions, disputes and referral cap. Verify contention, limits, indexes, reconciliation in emulator + stg; if integrity cannot be proven block live money and revisit storage. Backups and restore drill before real funds. Repository contracts and export format preserve portability. SGD minor units only in payment path, no Stripe FX; future currency/corridor modeled separately. Private uploads scanned, signed links, RBAC, retention, provenance. No secret or raw receipt in agent analytics.

## Stripe Connect and timing gate
Selected single provider; narrow payment adapter (create checkout, verify provider state, refund, transfer, payout, reconcile), no multi-provider implementation. Stripe-hosted onboarding/checkout proposed. Separate charges/transfers is a candidate, NOT approved custody; public funds segregation private preview excludes Singapore and PayNow. Alternative direct or destination charge plus controlled manual payout requires explicit merchant/fee/refund/rematch review. Do not enable live payments until Stripe and SG counsel confirm exact configuration, legal control, terms, 44+day retention, dispute handling and late refunds. No GetViaMe-held pooled bank funds, no shopper or traveller wallet; provider balance is not an escrow account. Read stripe-connect-launch-gates-v0.9.md.
PaymentAllocation stores original payment ID, gross, tender, effective provider hold/refund deadlines, remaining amount, intended recipient and rematch consent; immutable event and money journal, reserve platform-funded fees/subsidies separately, atomic refund/release/dispute/rematch state and outbox, provider idempotency keys + reconciliation on unknown responses, webhook signature and account/currency/amount verification. No arbitrary balance transfers or spend of customer principal for expenses. If integrity cannot be proven, block live funds and revisit storage.
Durable tasks for 30-day delivery maximum, actual report +3/+6/+7 days, confirmation +7 days, retention deadline alerts and weekly payouts. Never backdate to shorten rights. Batch only eligible cash obligations by connected account, validate payout capability and available balance, track transfer and bank payout separately. No automatic payout of disputed funds. Late refund exception workflow is human-authorized, verified original payer, no duplicate or wallet fallback. Cards deferred; promotions feature-flagged OFF until approved platform funding and legal classification.
